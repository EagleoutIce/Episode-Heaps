\begin{itemize}[<+(1)->]
    \itemsep15pt
    \item For us a tree is \begin{itemize}
        \item a graph \(G = (V, E)\) with \(\abs{V}\) nodes and \(\abs{E}\) edges
        \item \(V\) and \(E\) are finite
        \item acyclic \& connected (\say{maximally acyclic})
    \end{itemize}
    \item Even a binary tree! \begin{itemize}
        \item Every node has at most two successors
        \item We focus on balanced ones
    \end{itemize}
    \item Trees can be seen as a recursive structure
\end{itemize}
